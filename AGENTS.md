# Local Trades engineering rules

GetTradesmen.uk is the structural reference for this repository. Keep the same Next.js App Router architecture, SEO helpers, schema approach, breadcrumbs, sitemap/robots conventions, shared page templates and route conventions. Local Trades keeps its own branding, copy and MyJobQuote hosted-iframe flow.

Local SEO pages must not be produced by swapping only the place name. Before a new trade × location route is added to `PUBLISHED_LOCAL_PAGES`, add a researched location profile in `src/lib/localAreaContent.ts` and a genuinely location-specific `tradeContent` entry for that trade. Use useful local facts or constraints that can materially affect the job — for example housing type, rental context, conservation/Article 4 controls, protected trees, access, or other authoritative local information — and cite the primary source on the page. Keep generic trade guidance in the shared page structure; keep location × trade substance in the local content layer.

Keep the GetTradesmen internal-link architecture intact as the site scales. The homepage must expose the eight trade category routes. Every trade category route must link to every published location for that trade. Every published trade × location route must expose the other published trades in the same location through the shared site footer (and may also use contextual specialist links in the page body). `PUBLISHED_LOCAL_PAGES` is the single source of truth for indexable local routes and must feed both these internal links and `sitemap.ts`. Never add an unpublished/planned local route to the sitemap or navigation as if it exists.

Every public route must remain crawlable and indexable unless there is a deliberate documented reason otherwise. Keep the canonical host as `https://getlocaltrades.uk`, keep self-referencing canonicals through `createPageMetadata`, and keep `robots.ts` open to crawling with the sitemap declared. Trade pages must use the category-specific OG path (`/og/handyman.jpg`, `/og/plumber.jpg`, `/og/electrician.jpg`, `/og/roofer.jpg`, `/og/painter-decorator.jpg`, `/og/flooring-fitter.jpg`, `/og/builder.jpg`, `/og/gardener.jpg`); non-trade pages use `/og/home.jpg`. These filenames are stable so the image assets can be replaced later without changing page metadata.

Do not reintroduce Cloudflare Workers, HTMLRewriter, wrangler, a static public/index.html homepage, or injected iframe JavaScript/CSS.
