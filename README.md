# Local Trades

Local Trades is a UK homeowner information and referral website built with Next.js App Router and TypeScript.

## Architecture

This project deliberately follows the same structural conventions as GetTradesmen.uk: shared SEO/schema helpers, reusable trade and local-trade landing-page components, breadcrumbs, information/legal pages, dynamic robots and sitemap outputs, and trailing-slash canonical URLs.

The Local Trades visual identity and MyJobQuote hosted-iframe quote flow are site-specific.

## Development

```bash
npm install
npm run dev
```

Production target: Vercel.
